# Mayur Satpute — Portfolio

Personal portfolio website: team leadership, networking, desktop support, and client / personal projects.

Plain HTML, CSS and JavaScript — no build step.

- `index.html` — page content
- `style.css` — styles (light / dark theme, responsive)
- `script.js` — menu, theme toggle, scroll animations
- `render.yaml` — Render static site config

## Run locally

Open `index.html` in a browser.

## Deploy

Deployed on [Render](https://render.com) as a static site (see `render.yaml`).
